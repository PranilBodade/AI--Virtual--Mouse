# AI-Based Virtual Mouse Using Hand Gesture Recognition


## Project Description
This project allows users to control the computer mouse using hand gestures through a webcam.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- PyAutoGUI

## Features
- Hand detection
- Cursor movement using index finger
- Mouse click using thumb and index finger
- Real-time hand tracking

## How to Run
1. Install Python.
2. Install the required libraries.
3. Connect your webcam.
4. Run main.py.
5. Move your index finger to control the cursor.
